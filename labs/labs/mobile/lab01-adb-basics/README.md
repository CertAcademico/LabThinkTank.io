# Lab01 — ADB Básico

## Objetivo

Introducir Android Debug Bridge (ADB) para interacción con dispositivos Android.

---

# Temas

- adb devices
- adb shell
- instalación APK
- logcat
- paquetes Android

---

# Requisitos

- Android Studio
- Android Emulator
- ADB Platform Tools

---

# Verificar dispositivos

```bash
adb devices
```

---

# Abrir shell Android

```bash
adb shell
```

---

# Instalar APK

```bash
adb install diva-beta.apk
```

---

# Actividades

1. Crear emulador Android
2. Verificar conexión
3. Instalar APK vulnerable
4. Revisar paquetes instalados
